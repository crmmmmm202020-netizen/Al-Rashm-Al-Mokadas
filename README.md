# 🔥 أكاديمية الرشم المقدس

> **نرد بالحجة… ونحاور بالاحترام**

موقع تعريفي سينمائي لأكاديمية الرشم المقدس — **ثابت بالكامل**.
مفيش سيرفر، مفيش قاعدة بيانات، مفيش حسابات، مفيش رفع، مفيش Supabase ولا أي Backend.

## ⚡ تعديل بيانات الأعضاء

كل حاجة عن الأعضاء في **ملف واحد**: `assets/js/data/members.js`

```js
{ no: 1,  name: 'EAGLE',   role: 'قائد الأكاديمية ودعيس',  bio: '', image: '', tiktok: 'glorytotheeagle1' },
```

| الحقل | الوصف |
|---|---|
| `no` | رقم الترتيب — **ثابت**. هو اللي بيحدد الترتيب في الصفحة، لا تعدّله ولا تحذفه |
| `name` | الاسم — كما هو، بدون تعديل |
| `role` | الوصف / التخصص |
| `bio` | نبذة شخصية — **فاضية دلوقتي**، اكتب فيها اللي تحب |
| `image` | مسار الصورة — فاضي = صورة رمزية أنيقة مولّدة من أول حرف. مثال: `"assets/img/members/01.jpg"` |
| `tiktok` | اسم حساب TikTok **بدون** `@` — فاضي = الرابط مش مفعّل. مثال: `"glorytotheeagle1"` |

بعد التعديل: احفظ الملف واعمل تحديث للصفحة. **مفيش لوحة إدارة ولا تسجيل دخول** — التعديل يدوي بالملفات.

### إضافة صور الأعضاء

1. أنشئ مجلد `assets/img/members/`
2. حط الصور بأسماء مرقّمة (`01.jpg` … `27.jpg`) — **مربعة وقصيرة** (حوالي 300×300)
3. اكتب المسار في خانة `image` لكل عضو

الصور الناقصة أو التي يتعذّر تحميلها بتتحوّل تلقائيًا للصورة الرمزية الأنيقة.

## 🎬 الترات المتحركة

قسم الترات على `members.html` (وكمان شريط مصغّر على الصفحة الرئيسية):

- **بلا نهاية فعلية** — القائمة بتتنسر مرتين جنب بعض في الواجهة، والترجمة `-50%` بتخلّي الشريط يلف بلا أي قفزة مرئية بين العضو 27 والعضو 1.
- **البيانات ما بتتكررش** — التكرار في بناء الواجهة بس، مش في ملف البيانات.
- **إيقاف عند مرور المؤشر** — على الكمبيوتر.
- **احترام تقليل الحركة** — لو الجهاز مضبوط على «تقليل الحركة»، الشريط بيتحول لشريط ثابت قابل للتمرير بـ swipe.
- **الأسماء والأرقام واضحة** أثناء الحركة، وكل بطاقة قابلة للنقر لفتح حساب TikTok.

المدة الأساسية 75 ثانية للدورة الكاملة، وبتقل على الموبايل. تقدر تغيرها من:
```css
.credits { --credits-dur: 75s; }
```

## تسجيل زيارات الموقع (اختياري)

**GitHub Pages مابيدّيش سجلات زوار ولا عناوين IP.** عشان كده التسجيل هنا اختياري وبيروح لـ Google Apps Script مجاني، والبيانات بتتحفظ في Google Sheet بتاعك — مفيش سيرفر مدفوع ومفيش قاعدة بيانات تابعة للموقع.

**اللي بيتسجّل:** الوقت، IP، الصفحة، الدومين، المتصفح، النظام، نوع الجهاز، اللغة، المنطقة الزمنية، مقاس الشاشة، مصدر الزيارة، ومعرّف عشوائي للمتصفح (مش ID جهاز حقيقي).

**اللي مستحيل يتسجّل:** حسابات الزوار على TikTok/Telegram، كلمات المرور، أو رقم جهازهم — المتصفح مابيوفّرهاش أصلاً. كمان الزائر لو فعّل «عدم التتبع» (Do Not Track) مش بيتسجّل.

### التركيب خطوة بخطوة

1. افتح [sheets.new](https://sheets.new) واعمل شيت جديد (اسمه مثلًا «زيارات الأكاديمية»).
2. من الشيت: **Extensions → Apps Script**.
3. امسح الكود اللي موجود في `Code.gs`، وانسخ محتوى الملف `google-apps-script/visits-logger.gs` كله والصقه.
4. احفظ المشروع.
5. من Apps Script: **Deploy → New deployment → Web app**.
   - **Execute as:** `Me`
   - **Who has access:** `Anyone` (مش «Anyone with Google account»)
   - اضغط **Deploy** ووافق على الصلاحيات. لو ظهر تحذير «unverified app» اضغط **Advanced → Go to project** (ده سكريبت شخصي بتاعك).
6. انسخ **Web app URL** (لازم ينتهي بـ `/exec`).
7. افتح `assets/js/data/members.js` وحط الرابط في:
   ```js
   visitorLogUrl: 'https://script.google.com/macros/s/.../exec',
   ```
8. افتح محرر Apps Script وشغّل الدالة `setupDailyReport` **مرة واحدة** — دي بتظبط إيميل يومي الساعة 8 الصبح بملف CSV بزيارات اليوم اللي فات.
9. ارفع الموقع على GitHub. أول ما حد يفتح صفحة، هيظهر صف جديد في شيت «الزيارات».

> لو عدّلت `visitorLogUrl` بعد ما الموقع اتنشر، غيّر رقم النسخة `?v=5` في وسم `data/members.js` بالصفحتين لرقم أكبر (مثلًا `v=6`) عشان تمنع الكاش القديم.

**للإيقاف:** سيبه فاضي (`visitorLogUrl: ''`) أو احذف الـ deployment/الـ trigger. الإشعار في التذييل بيظهر بس لما التسجيل يكون مفعّل.

### ملاحظات مهمة

- تسجيل الـ IP بيتم عن طريق خدمة `api.ipify.org` من متصفح الزائر. لو الزائر عنده مانع إعلانات/حماية بتمنعها، الصف بيتسجل من غير IP.
- الرابط العام للـ Web App ممكن حد يلاقيه ويبعتله بيانات وهمية؛ فيه حد أقصى 10 ثواني بين كل تسجيلين من نفس الـ IP، لكنه **مش دليل قاطع** على هوية حد. استخدمه كإحصاء وإنذار أمني، مش كإثبات.
- **الخصوصية:** الإشعار ظاهر في التذييل، وبيحترم DNT. بيانات الـ IP بيانات شخصية؛ استخدمها في نطاق الأمن والإحصاء بس، وماتشاركهاش. راجع قانون حماية البيانات المصري رقم 151 لسنة 2020 قبل أي استخدام موسّع.
- عايز حماية أقوى للحساب؟ فعّل **2FA** على GitHub، وما تحطش أي توكنات/مفاتيح في ملفات الموقع.

## 🚀 النشر على GitHub Pages

الموقع ثابت بالكامل — الرفع مباشر ومن غير أي إعدادات بناء:

```bash
git init
git add .
git commit -m "موقع أكاديمية الرشم"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

ثم من المستودع: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.

الملف `.nojekyll` موجود بالفعل عشان GitHub Pages ما يبسّطش الملفات، ومفيش أي خطوة بناء (npm/build) عشان الموقع HTML و CSS و JS نقي.

**تنبيه:** كل المسارات نسبية (`assets/...`)، فيشتغل على GitHub Pages وعلى أي استضافة ملفات ثابتة، وحتى بفتح `index.html` مباشرة من القرص.

### لو ظهر خطأ `No such file or directory @ dir_chdir0 - .../docs`

معناه إن GitHub Pages متضبط على مجلد `docs` مش موجود في المستودع، والموقع كله موجود في الجذر. الحل:

1. افتح المستودع → **Settings** → **Pages**.
2. تحت **Build and deployment** اختار **Source: Deploy from a branch**.
3. **Branch:** `main` — **Folder:** **`/ (root)`** → **Save**.
4. اتأكد إن ملف `.nojekyll` مرفوع في جذر المستودع (مش متجاهَل في `.gitignore`).
5. استنى دقيقة، وافتح الرابط اللي فوق في نفس الصفحة.

لو لسه فيه Workflow قديم اسمه Jekyll بيفشل مع كل تعديل، فمش مؤثر بعد ما تخلي المصدر Branch، وتقدر تمسحه من `.github/workflows` لو موجود.
